## Common Issues & Solutions

### Issue: CSV File Shows Garbled Characters
**Solution:**
- Open with UTF-8 encoding
- In Excel: Data → From Text → Choose UTF-8 encoding
- Or use text editor that supports UTF-8 (VS Code, Sublime)

### Issue: Excel Shows Corruption Warning
**Cause:** openpyxl not installed or old version
**Solution:**
```bash
bench pip install --upgrade openpyxl
```

### Issue: PDF Generation Fails
**Cause:** wkhtmltopdf not installed
**Solution:**
```bash
# macOS
brew install wkhtmltopdf

# Ubuntu/Debian
sudo apt-get install wkhtmltopdf

# Check installation
which wkhtmltopdf
```

### Issue: Export Hangs/Timeout
**Cause:** Large dataset
**Solution:**
- Test with smaller report first
- Check Frappe logs: `bench logs`
- Increase timeout in `frappe/utils/pdf.py` if needed

### Issue: File Not Downloading
**Cause:** File storage issue
**Solution:**
```bash
# Check private files directory
ls -la sites/{site}/private/files/

# Check permissions
chmod 755 sites/{site}/private/files/
```
